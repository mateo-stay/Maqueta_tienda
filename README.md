# Micelio — tienda demo de melena de león

Maqueta estática responsive para GitHub Pages.

## Funcionalidades
- Catálogo con cápsulas, polvo y extracto líquido.
- Filtros por formato.
- Carrito con cantidades y total estimado.
- Compra simulada que descuenta unidades del inventario.
- Panel de administración para editar precios y existencias.
- Secciones de quiénes somos y contacto.

## Publicar en GitHub Pages
1. Abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)**.
4. Pulsa **Save** y espera a que termine la publicación.

## Limitaciones
Esta es una demostración frontend. El inventario se guarda solo en localStorage del navegador y no se sincroniza entre compradores. No procesa pagos ni envía formularios. Los productos, precios y existencias son ficticios. Las imágenes se cargan desde URLs externas. El contenido no constituye consejo médico.
